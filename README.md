# PCA and Apriori Association Rule

This repository contains two machine learning and data mining practical projects implemented using Python and Jupyter Notebook.

## Projects Included

### 1. Principal Component Analysis (PCA)

Principal Component Analysis (PCA) is a dimensionality reduction technique used to reduce the number of features in a dataset while preserving important information.

**File:** `PCA.ipynb`

The notebook demonstrates the implementation of PCA using Python and relevant machine learning libraries.

### 2. Apriori Association Rule

The Apriori algorithm is an association rule mining technique used to discover relationships and frequent patterns among items in a dataset.

**File:** `Apriori_Assocation_rule.ipynb`

The notebook demonstrates how association rules can be generated from transactional data using the Apriori algorithm.
